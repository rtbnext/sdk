# @rtbnext/sdk

**Official JavaScript/TypeScript SDK for the RTBNext API.**

The RTBNext SDK provides a typed, asynchronous interface for accessing
billionaire profiles, lists, filters, statistics, historical data and
system information from the RTBNext API.

The SDK follows a consistent resource-oriented design: resources are
loaded lazily, cached according to the configured cache mode, and expose
typed helper methods for collections, time series and indexed data.
